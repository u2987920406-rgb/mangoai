**Élève — GLM-5.2 via Ollama Cloud (actif depuis 2026-06-22) :**
Aucun process local à lancer pour l'Élève : il passe par l'API cloud (`ELEVE_PROVIDER=openai`, `ELEVE_API_URL=https://ollama.com/v1`, `ELEVE_API_KEY`, `ELEVE_MODEL=glm-5.2:cloud` dans `server/.env`). Vérif rapide :
```bash
curl https://ollama.com/v1/chat/completions -H "Authorization: Bearer $ELEVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"glm-5.2:cloud","stream":false,"messages":[{"role":"user","content":"ping"}]}'
```
**Repli Élève local** (décommenter `ELEVE_MODEL=gemma4:12b` + retirer les 3 lignes provider) :
```bash
ollama serve
```
Embeddings (toujours locaux, pour Notes/PDF/RAG) : `nomic-embed-text` (274 Mo) via `ollama serve`.
